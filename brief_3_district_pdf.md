# Claude Code Brief 3/4 — District Policy Brief (One-Page PDF)

**Goal:** Generate a one-page, printable PDF brief per district — the artifact a policy maker holds, files, emails, and walks into a meeting with. Packages everything you've built (risk, drivers, people-at-risk, burden-days, institution recommendations, scheme alignment) into one legible page.

**Scope:** This brief only. A PDF generator consuming existing district data. Do NOT change the model or data.

---

## Why this is the deliverable

Governments act on documents, not dashboards. This brief turns your platform's outputs into the format that circulates in a ministry. It's also a quality test: if a district's story doesn't fit clearly on one page, the outputs aren't decision-ready.

---

## Input

Reads existing outputs: `district_rankings.json`, the institution recommendations, demographics, burden-days, and (if available) the gap/future fields. One PDF per district; also support generating a batch for a whole state.

## Layout — one page, top to bottom

### Header
- District name, State
- Overall risk score (large) + national rank (e.g. "Rank 23 of 707")
- Risk tier badge (critical / high / moderate / low)

### Section 1 — The Climate Threat
- Dominant hazard(s) with scores (e.g. "Flood 8.2 · Heat 6.1")
- Burden: "X days/year under WASH stress (Y compounded)" — the suffering-time metric
- If future data present: "Risk rises to Z by 2050 (SSP5-8.5); dominant hazard shifts to ___" — the gap insight

### Section 2 — Who Is At Risk (the disaggregated weight)
- Total population at risk
- Children under 5: N
- Women 15–49: N
- Elderly 60+: N
- (Visually emphasised — these numbers are the political weight)

### Section 3 — Why (drivers)
- Short explanation: dominant hazard + top vulnerabilities (e.g. "High flood hazard compounded by poor sanitation (41%) and groundwater stress")
- A small bar showing hazard / exposure / sensitivity / adaptive-capacity contributions

### Section 4 — Recommended Actions (the three institutions)
Three compact blocks:
- 🏫 **Schools:** [top 2 measures] — funded by [scheme]
- 👶 **Anganwadis:** [top 2 measures] — funded by [scheme]
- 🏠 **Households:** [top 2 measures] — funded by [scheme]

### Footer
- Data sources (NFHS-5, CHIRPS/ERA5, WRIS, WorldPop, CMIP6) + methodology URL
- "Generated by ClimResWASH · [date]"
- Small disclaimer (model estimates, not a substitute for ground assessment)

---

## Implementation

Use the existing pdf skill / a clean HTML→PDF approach (reportlab or weasyprint or the repo's existing tooling). Keep it ONE page, clean, government-appropriate (sober, not flashy). District map thumbnail optional if easy (the district's hexes colored by risk).

Output: `reports/briefs/<state>_<district>.pdf`. Batch mode: `reports/briefs/<state>/` for all districts in a state.

A CLI: `python scripts/generate_brief.py --district "Araria" --state "Bihar"` and `--state "Bihar" --all`.

## Acceptance criteria

- [ ] One-page PDF per district with all 4 sections + header/footer
- [ ] People-at-risk disaggregated (children/women/elderly) prominently shown
- [ ] Burden-days (suffering-time) included
- [ ] Three institution recommendation blocks with scheme alignment
- [ ] Future/gap line included if data present (graceful if not)
- [ ] CLI for single district + whole-state batch
- [ ] 3 sample briefs generated and confirmed one-page, fully populated
- [ ] Sober, government-appropriate design
- [ ] Reads existing data only; model unchanged

---

## Rules for Claude Code

1. Read the pdf SKILL.md before generating PDFs.
2. ONE page — if content overflows, tighten, don't spill to page 2.
3. People-at-risk disaggregation is the political payload — make it prominent.
4. Recommendations must match the district's actual dominant hazard.
5. Graceful if future/gap data absent (omit that line, don't crash).
6. Sober government design — not a marketing flyer.
7. Generate 3 sample briefs, confirm one-page, then stop.
